# Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.  
This project helps users manage their daily expenses by adding, viewing, and deleting expense records with automatic total calculation.

---

## Features

- Add new expenses
- Delete expenses
- View expense history
- Automatic total expense calculation
- User-friendly interface
- Responsive design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
